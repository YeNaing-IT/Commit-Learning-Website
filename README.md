# Commit — Learning Progress Platform

**Turn learning goals into action. Build consistency. Show your progress.**

Commit is a learning productivity web application designed to help developers follow through on what they start learning. It transforms courses and roadmaps into manageable milestones, focused work sessions, and tangible evidence of progress.

Instead of simply collecting courses or tracking study hours, Commit encourages users to finish meaningful tasks and document what they have built.

## Live Demo

**[Visit Commit](https://yenaing-it.github.io/Commit-Learning-Website/)**

## Overview

Learning a new skill is easy to start but difficult to finish. Commit helps bridge that gap by giving learners a clear next step, a structured learning path, and a way to demonstrate their progress.

The platform is built around three principles:

- **One path:** Focus on a learning goal at a time.
- **One next step:** Break large goals into achievable milestones.
- **One piece of proof:** Record completed work and demonstrate acquired skills.

## Features

- **Learning Path Management** — Organise courses, roadmaps, and personal learning goals into structured paths.
- **Milestone Tracking** — Break learning objectives into smaller, actionable tasks.
- **Focused Study Sessions** — Work on a specific milestone and maintain a record of each session.
- **Roadmap Integration** — Start with a template, create a learning path manually, or import a public roadmap and customise its milestones.
- **Evidence of Progress** — Connect completed milestones to repositories, commits, pull requests, demos, and articles.
- **Progress Tracking** — Monitor completed milestones, learning activity, and evidence of work.
- **Privacy-Focused Publishing** — Keep learning evidence private by default and choose what to share publicly.

## How It Works

1. **Choose a learning path** based on a skill, course, or roadmap.
2. **Define your next milestone** so you know exactly what to work on.
3. **Start a focused session** and make measurable progress.
4. **Attach evidence** such as code repositories, commits, or project demonstrations.
5. **Review your progress** and move on to the next milestone.

## Project Goals

- Encourage consistent learning habits.
- Make large learning goals easier to complete.
- Connect learning activities with practical project outcomes.
- Help developers build a portfolio of demonstrable skills.
- Keep progress tracking focused on completed work rather than vanity metrics.

## Future Improvements

Potential areas for further development include:

- More learning path templates.
- Enhanced milestone analytics and progress visualisations.
- Additional integrations with developer platforms.
- Customisable weekly learning goals.
- Improved sharing and portfolio presentation options.
